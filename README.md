## Quick Start

### 1. Install dependencies
```bash
cd presales_v4/backend
pip install -r requirements.txt
```

### 2. Set up LLM
```bash
# Option A: Ollama (recommended — free, on-premises)
ollama pull qwen2.5:14b
ollama pull nomic-embed-text

# Option B: OpenAI — edit .env
cp .env.example .env
# Set LLM_PROVIDER=openai and OPENAI_API_KEY=sk-...
```

### 3. Start the backend
```bash
cd presales_v4/backend
python server.py
# Server runs at http://localhost:8000
```

### 4. Open the UI
Open `presales_v4/frontend/public/index.html` in your browser.
Or visit http://localhost:8000 if you copy the HTML into the backend's static folder.

## Workflow (5 stages)

1. **Customer Query** — Paste the customer's requirements
2. **AI Questions** — CrewAI agents extract requirements and ask 4-6 clarifying questions
3. **Document Generation** — All 15 documents generated by 19 specialist agents
4. **Review & Approve** — Preview each document, leave feedback, approve
5. **Publish** — Download complete ZIP package

## Adding New Industries

### Via UI (Knowledge Base page):
1. Click "Knowledge Bases" in header
2. Enter industry name and content
3. Save — available immediately for new sessions

### Via API:
```bash
curl -X POST http://localhost:8000/api/knowledge-base \
  -H "Content-Type: application/json" \
  -d '{"industry": "Steel", "content": "# Steel Manufacturing...", "description": "Hot/cold rolling mills"}'
```

### Via file:
Create `backend/data/steel/knowledge.txt`

## API Endpoints
- POST /api/sessions/start         — Start new session
- GET  /api/sessions/{id}          — Get session state
- POST /api/sessions/{id}/answer   — Submit clarifying answers
- POST /api/sessions/{id}/skip-questions — Skip to generation
- POST /api/sessions/{id}/review   — Approve/reject documents
- POST /api/sessions/{id}/publish  — Publish package
- GET  /api/sessions/{id}/download — Download ZIP
- GET  /api/sessions/{id}/preview/{doc_id} — Preview PDF
- GET  /api/industries             — List knowledge bases
- POST /api/knowledge-base         — Create knowledge base
- WS   /api/ws/{id}               — Real-time progress
